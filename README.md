# Pour Guide

핸드드립 레시피를 직접 만들고, 추출 중 언제 몇 그램을 붓고 어떤 행동을 해야 하는지 실시간으로 안내하는 웹앱입니다. GitHub Pages에서 동작하며 별도 계정이나 서버가 필요 없습니다.

## 기능

- **순차 레시피 편집**: 단계별 시간, 추가 물량, 붓기·기다리기·스월링·스티어링을 입력합니다.
- **실시간 가이드**: 실제 경과 시간 기준으로 현재 단계, 누적 목표 물량, 추가로 부을 양, 남은 시간과 다음 단계를 표시합니다.
- **정확한 일시정지와 재개**: 탭이 백그라운드로 밀려도 벽시계 시간으로 보정합니다.
- **붓기 진행 표시**: 붓기 단계에서는 목표 누적 물량이 시간에 따라 증가합니다.
- **레시피 보관**: 브라우저 로컬 저장, JSON 내보내기·가져오기, 예제 레시피 3종.
- **모바일 우선 화면**: 큰 타이머와 물량, 추출 중에도 읽기 쉬운 단계 카드, 키보드 접근성과 모션 감소 지원. 터치 기기와 좁은 화면에서는 입력창·선택창의 글꼴을 16px로 유지해 입력 시 자동 확대를 방지하며, 사용자의 핀치 확대는 허용합니다.
- **소리 알림**: 사용자가 켠 경우에만 단계 전환음이 납니다. 음소거 해제 시 확인음이 울리고 이후 단계 알림이 다시 재생됩니다. 브라우저가 소리를 막으면 화면에 안내합니다.

물량은 **각 단계에서 추가로 붓는 양**입니다. 시작 시각은 단계 시간을 누적하여 자동 계산되므로 별도로 입력할 필요가 없습니다.

## 시작하기

```bash
npm install
npm run dev
```

개발 서버는 `http://127.0.0.1:5173/pour-guide/`에서 열립니다.

```bash
npm test        # 계산·타이머 동작 검증
npm run build   # 타입 검사 + 프로덕션 빌드
npm run preview # 빌드 결과 로컬 확인
```

## GitHub Pages 배포

`.github/workflows/deploy.yml`은 `main` 브랜치에 푸시하면 테스트, 빌드, Pages 배포를 실행합니다. 저장소 **Settings → Pages → Source**는 **GitHub Actions**여야 합니다.

공개 주소: <https://licht0182.github.io/pour-guide/>

Vite의 `base`는 저장소 하위 경로(`/pour-guide/`)에 맞춰 설정되어 있습니다. 저장소 이름을 바꾸면 `vite.config.ts`의 `base`도 함께 바꿉니다.

## 데이터와 개인정보

레시피는 사용자의 브라우저 `localStorage`에만 저장되며 서버로 전송되지 않습니다. 사이트에는 분석 도구나 추적 스크립트가 없습니다. 브라우저 저장 공간을 비우면 사용자 레시피도 삭제되므로 중요한 레시피는 JSON으로 내보내 보관하세요.
